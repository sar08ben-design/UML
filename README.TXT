PROJECT TITLE: Game Project

PURPOSE OF PROJECT:
This project is a Java program that manages a collection of 
games using object-oriented programming. It demonstrates classes, inheritance, enums, and a HashSet-based game library.

VERSION or DATE:
May 1, 2026

HOW TO START THIS PROJECT:
Open the project in BlueJ and compile all classes.
To run outside BlueJ, open a terminal in the project folder and use:
javac *.java
java Driver

AUTHORS:
Sarah, Anuj

USER INSTRUCTIONS:
##Files
Game.java, SinglePlayer.java, Multiplayer.java, Online.java, Local.java
GameLibrary.java
Genre.java, AgeRating.java, Platform.java

##Features
--Create games with title, genre, age rating, platform, and rating.
--Store games in a GameLibrary that uses HashSet<Game>.
--Add, remove, and list games.
--Use inheritance for single-player and multiplayer game types.
--Simple menu in Driver.main for user interaction.
